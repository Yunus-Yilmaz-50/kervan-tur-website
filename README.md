# Kervan Kültür Turları – Website

Individuelles WordPress-Theme für ein Reiseunternehmen, von Grund auf entwickelt : kervan-tur.com

## Features
- Eigenes Tour-Verwaltungssystem mit Filtern (Kontinente, Zeitraum, Sortieren, Favoriten)
- WhatsApp-basierter Anmeldeprozess mit dynamischem Formular
- Admin-Einstellungsseiten für alle Inhalte, ohne Code-Kenntnisse pflegbar
- Mehrsprachige Inhalte, KVKK-konforme Datenschutzseiten

## Tech-Stack
PHP, WordPress (ohne Page-Builder), Vanilla JavaScript, CSS
